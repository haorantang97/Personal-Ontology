# 模型能力与并发建议

不绑定厂商、型号或固定 agent 数。使用用户当前模型，并按风险选择能力档：

- 普通能力：格式化、确定性准备、低歧义 Map、独立 QA 扫描；
- 高级能力：高歧义引用、领域事件时间/主体判定、跨事件冲突、反例、声音约束、最终综合；
- 人工：身份不确定、证据边界不可判、价值冲突和知识库批准。

切换能力档前做小型 shadow canary，同时测结构合规、证据精确率和召回率。达到 canary 样本后若结构/内容拒绝呈系统性，控制器停止补位；人工检查契约或模型后再建立新 run scope。更快、更便宜或结构更整齐，不等于证据召回足够。

并发由当前独立 packet 数、基础设施错误和本地 validator backlog 动态决定。基础设施失败时暂时降低目标；同类错误连续出现时进入限流/冷却，并建议回退到更小 packet、本地确定性步骤或安全替代能力档。内容失败先隔离单元，只有 canary 判定系统性时全局停喂。用完成驱动补槽，不等待整波最慢任务。

在跨领域 Merge、冲突判定、自我模型、Voice 和 Final 等高风险阶段，可以从普通能力小样本起步，只在召回、归因或冲突门未通过时升级能力档。多个领域包互不依赖时可使用动态子 agent 并行，但各自的冻结分母、证据门和失败隔离不变。

并发发生在模型推理层；本地 ledger 保持单 writer。控制器先串行 claim，再分发 packet，结果可并行返回但按本地验证/commit 队列落账。

报告目标并发与真实 in-flight 的差别。没有 Fast 开关，任何吞吐优化都不能跳过隐私、依赖、验证或 receipt。
