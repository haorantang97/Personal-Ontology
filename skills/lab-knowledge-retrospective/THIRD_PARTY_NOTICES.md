# Third-Party Notices

This Skill bundles no third-party executable component.

It reads method pages and hands approved conclusions to `lab-knowledge-intake` through the `agent-knowledge` MCP gateway shipped in [`lab-ontology/`](../../lab-ontology/README.md); that module's own notices list the runtime software it relies on. Other skills named in `SKILL.md` as neighbouring memory stores (for example `gstack-*` or `dbs-*`) are optional, separately installed tools under their own terms and are not bundled here.
